# Sân Vườn Cố Đô

Website tĩnh giới thiệu dịch vụ thiết kế, thi công và chăm sóc cảnh quan:
sân vườn biệt thự, hồ cá Koi, cafe và nhà hàng sân vườn, tiểu cảnh,
tường cây, vườn đứng, tiểu cảnh giếng trời, sân thượng, cầu thang và nhà phố.

Phong cách: hiện đại, sang trọng, tông xanh lá cây và trắng.

## Chạy thử tại máy

Mở file `index.html` bằng trình duyệt, hoặc chạy một static server, ví dụ:

```bash
python3 -m http.server 8000
```

Sau đó mở http://localhost:8000

## Xuất bản bằng GitHub Pages

1. Vào repo trên GitHub → **Settings** → **Pages**.
2. Ở mục **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn nhánh `main` và thư mục `/ (root)`, rồi lưu lại.

## Lưu ý

- Nội dung trên trang là nội dung gốc, được viết mới cho dự án này.
- Form tư vấn hiện là bản trình bày tĩnh, chưa gửi dữ liệu đi đâu.
  Khi đưa vào vận hành, hãy nối form với email hoặc hệ thống CRM của bạn.
- Các khung dự án hiện dùng nền chuyển sắc xanh lá. Khi có ảnh công trình
  thật, hãy thay các khung đó bằng ảnh thật để trang thuyết phục hơn.
